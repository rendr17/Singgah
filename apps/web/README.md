# @singgah/web

SvelteKit web app (PWA-first surface). All commands run from the repo root:

```bash
pnpm dev          # vite dev server
pnpm check        # svelte-check typecheck
pnpm test         # vitest unit tests
pnpm build        # production build
```

Formatting is unified at the repo root (`pnpm format` / `pnpm format:check`).
