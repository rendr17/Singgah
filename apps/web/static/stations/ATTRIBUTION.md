All files are from Wikimedia Commons under free licenses; attribution is also
rendered in-app next to the photo via `src/lib/station-photos.ts`.

Adding a photo: download a licensed image (Commons preferred), convert to
≤960px WebP, add the file here, map the stop's display name (lowercase) in
`station-photos.ts`, and append a row to this table.
